# The Best Meal You Ever Had

Entry for the [make.fun bounty](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85):
write one sentence, at most 200 characters, about the best meal you ever had.

## The entry

> My best meal was hospital food: plain chicken porridge my sister smuggled in after my surgery, lukewarm and unsalted, and the first thing that tasted like being alive again.

(173 characters, one sentence.)

## How it works

`main.ts` writes the sentence deterministically to `/output/entry.txt`
(two runs produce byte-identical output) and enforces the gate itself:
1–200 characters, not only white space.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```
